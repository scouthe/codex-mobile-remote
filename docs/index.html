Why remote mode

One execution host.
Everywhere you need it.

The app wraps the existing Vue UI in a focused Kotlin shell. It does not install a second Codex runtime on the phone, so desktop threads, progress, and writer ownership stay consistent.

👀

Live observer

Open existing threads and follow thinking, commands, file changes, approvals, and final results through the shared event stream.

📬

Safe controls

Send normal messages to the queue, steer the active turn, or request an interrupt without creating a competing writer.

🔔

Native Android UX

Reconnect on network changes, receive task notifications, choose files, share text, and use the clipboard from Android.

Get started

Build and connect in minutes.

Run codexapp on the computer

Build the server and start it on the port you choose, for example --port 5900 --no-open --no-tunnel.

Expose it privately

Use tailscale serve --https=443 http://127.0.0.1:5900, then copy the HTTPS hostname.

Build the APK

Install JDK 17 and Android SDK 35, run the commands below, and install the generated debug APK.

Enter the endpoint

Open the app, enter the HTTPS URL and password if required, and tap Connect.

# server/frontend verification
pnpm install
pnpm run build:frontend
pnpm run build:cli

# Android remote client
cd android
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
Security

Designed for a private tailnet.

The remote shell stores the endpoint and encrypts the optional server password with Android Keystore. Keep the server behind Tailscale ACLs, do not expose --no-password publicly, and review the Codex sandbox/approval policy on the computer.

🔐

HTTPS first

HTTPS is the default. Plain HTTP is an explicit opt-in for trusted local Wi-Fi only.

🧭

Scoped navigation

WebView navigation is restricted to the configured origin and external links open outside the app.

🧹

Easy reset

Long-press the settings button to clear the saved endpoint, password, cookies, and client session.
