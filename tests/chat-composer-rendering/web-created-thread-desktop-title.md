# Web-created thread title in Desktop

## Prerequisites

- Open the web app and Windows Codex Desktop against the same Ubuntu Codex home.
- Choose a project with no active turn.

## Steps

1. Start a new thread from the web app with a short, unique prompt.
2. Wait for the web title to settle, then refresh the project list in Desktop.
3. Compare the title and position of the new thread in both clients.
4. Send a second prompt in the new thread and refresh Desktop again.

## Expected results

- Desktop shows the same generated title as the web app, not the project path.
- The new thread appears once in the project list. Its position reflects recent activity after a refresh.
- Sending another prompt does not erase the shared title.

## Cleanup

- Archive the test thread in either client.
